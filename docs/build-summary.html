What it is

A purpose-built platform replacing the Sligo Tech Meetup workflow with a single web property. Members sign up with name + email, RSVP to events with one click from email, and organisers manage everything from a brand-led dashboard. Built end-to-end against the Nexus Northwest Functional Specification v1.2 and most of its Phase 2 list.

Architecture highlights

  • Boundaries kept clean — Zoho, email, WhatsApp, rate-limit, tokens all behind interfaces; swap providers without touching callsites
  • Tokens — HMAC-signed via TOKEN_SECRET, DB-backed for instant revocation. RSVP tokens reusable; unsubscribe single-use; survey tokens 30-day TTL
  • RBAC — capability matrix matches spec §4 row-for-row; server-enforced; tested per role
  • Reliability — sign-up never blocks on Zoho or email failures; failures persist for retry; durable Inngest steps when configured
  • Compliance — GDPR Article 17 + 20 self-service from preferences page; 30-day grace; daily scrub cron; soft-deleted members excluded from every recipient query
  • Brand-led UX — Poppins typography, navy/teal palette pulled from nexusnorthwest.org, animated hero, glass cards, accessible focus states, prefers-reduced-motion honoured
